## 인증

### 회원가입
- 목적 : 최소 정보(닉네임, 아이디, 비밀번호)만으로 빠르게 회원가입을 완료한다.
- 상세 요소 : 닉네임 / 아이디(+중복 확인) / 비밀번호 / 비밀번호 확인, 회원가입 버튼
- 기능 설명
  - ① 닉네임을 입력한다.
  - ② 아이디를 입력하고 중복 확인을 진행한다.
  - ③ 비밀번호와 비밀번호 확인을 입력한다.
  - ④ 회원가입 버튼을 누르면 계정이 생성된다.
  - ⑤ 회원가입 완료 후 온보딩 화면으로 이동한다.
- [회원가입] 활성 조건: 4개 필드 모두 조건 충족 + 아이디 중복 확인 완료가입 완료 → 온보딩(ONB-001)

### 로그인
- **목적** : 등록된 계정으로 서비스를 이용한다.
- **상세 요소** : 아이디, 비밀번호, 로그인 버튼
- **기능 설명**
  - ① 아이디를 입력한다.
  - ② 비밀번호를 입력한다.
  - ③ 로그인 버튼을 누른다.
  - ④ 인증에 성공하면 홈 화면으로 이동한다.

  •**[로그인] 활성 조건** : 아이디와 비밀번호 입력 완료

### 로그아웃
- **목적:** 현재 로그인 상태를 종료한다.
- **상세 요소:** 로그아웃 버튼
- **기능 설명**
  - 로그아웃 버튼을 클릭한다.
  - 로그아웃이 완료된다.
  - 로그인 창으로 이동한다.
- **활성 조건:** 로그인 상태

### 회원 탈퇴 및 탈퇴 완료
- **목적:** 사용자의 계정과 모든 데이터를 삭제한다.
- **상세 요소:** 회원 탈퇴 버튼, 탈퇴 확인 모달
- **기능 설명**
  - 사용자가 회원 탈퇴를 요청할 수 있다
  - 탈퇴 전 삭제되는 데이터를 안내하고 최종 확인을 받는다.
  - 탈퇴가 완료되면 계정 정보, 고민 기록 및 인사이트 데이터를 삭제한다.
  - 탈퇴 완료 화면을 제공한다.
  - 완료 화면에서 확인 버튼 선택 시 로그인 화면으로 이동한다.
- **활성 조건:** 로그인 상태에서 설정 > 회원 탈퇴 메뉴에 진입한 경우

## 온보딩

### 온보딩 조회
- **목적:** 서비스의 핵심 가치와 기록 방법을 이해하고 첫 기록을 시작할 수 있도록 안내한다.
- **상세 요소:** 진행 표시(Progress Indicator), 다음 버튼, 건너뛰기 버튼
- **기능 설명**
  - 최초 회원가입 시 온보딩을 1회 제공한다.
  - 단계별 화면을 순서대로 조회한다.
  - 다음 버튼 선택 시 다음 단계로 이동한다.
  - 마지막 단계에서는 첫 기록 작성 화면을 제공한다.

  •**활성 조건:** 최초 회원가입 완료 후 최초 로그인한 경우

  ### 온보딩 기록 작성
  - **목적:** 사용자가 실제 기록 방식을 경험하며 첫 기록을 생성할 수 있도록 한다.
- **상세 요소:** 고민 입력, 주제 선택, 오늘의 판단 입력, 이유 입력, 가치 선택, 가볍게 시도해보기 버튼
- **기능 설명**
  - 고민, 오늘의 판단, 이유를 입력한다.
  - 가치를 1개 선택한다.
  - '가볍게 시도해보기' 버튼 선택 시 입력한 내용을 첫 기록으로 저장한다.
  - 저장 완료 후 홈 화면으로 이동한다.
- **활성 조건:** 온보딩 마지막 단계 진입 시

## 메인

### 진행 중인 고민 조회
- **목적:** 사용자가 진행 중인 고민을 확인하고 이어쓰기할 수 있도록 한다.
- **상세 요소:** 진행 중인 고민 영역, 고민 카드, 고민 리스트, 고민 개수, 이어쓰기 버튼
- **기능 설명**
  - 진행 중(고민 중) 상태의 고민을 조회한다.
  - 진행 중인 고민을 최대 3건까지 노출한다.
  - 진행 중인 고민은 마지막 기록일이 오래된 순으로 정렬한다.
  - 진행 중인 고민이 1건인 경우 카드 형태로 노출한다.
  - 진행 중인 고민이 2~3건인 경우 리스트 형태로 노출한다.
  - 이어쓰기 버튼 선택 시 해당 고민의 이어쓰기 화면으로 이동한다

  •**활성 조건:** 홈 화면 진입 시

### 이어쓰기
 - **목적:** 새로운 고민을 생성하거나 새로운 기록 작성을 시작할 수 있도록 한다.
- **상세 요소:** 오늘 기록하기 버튼
- **기능 설명**
  -  '오늘 기록하기' 버튼 선택 시 새 고민 작성 화면으로 넘어간다.
- **활성 조건:** 홈 화면에서 '오늘 기록하기' 버튼 선택 시

### 이번달 가치 분포 조회
- **목적:** 사용자가 이번 달 가치 선택 경향을 확인할 수 있도록 한다.
- **상세 요소:** 가치 분포 카드
- **기능 설명**
  - 이번 달 작성한 기록을 기준으로 가치 분포를 계산한다.
  - 가장 많이 선택한 가치를 대표 가치로 노출한다.
  - 직전 월과 비교한 대표 가치 선택 비율의 증감률을 표시한다.
- **활성 조건:** 홈 화면 진입 시

### 최근 기록 조회
- **목적:** 최근 작성한 기록을 빠르게 확인할 수 있도록 한다.
- **상세 요소:** 최근 기록 목록
- **기능 설명**
  -  최근 작성한 기록을 최신순으로 최대 3건까지 조회한다.
  - 기록 제목, 작성일, 고민 상태를 함께 표시한다.
- **활성 조건:** 홈 화면 진입 시

## 고민 기록

### 새 고민 작성
- **목적:** 새로운 고민을 생성하고 기록을 시작할 수 있도록 한다.
- **상세 요소:** 새 고민 탭, 고민 입력, 주제 선택
- **기능 설명**
  - 새 고민 탭을 선택하여 새로운 고민을 생성한다.
  - 고민 제목과 주제를 최초 1회 입력한다.
  - 생성된 고민은 하나 이상의 기록을 가질 수 있다.
- **활성 조건:** 기록 작성 화면에서 새 고민 탭 선택 시

### 기록 입력
- **목적:** 기록 저장에 필요한 정보를 입력한다.
- **상세 요소:** 판단 입력, 이유 입력
- **기능 설명**
  - 오늘의 판단을 입력한다.
  - 이유를 입력한다.
  - 글자 수 제한을 적용한다.
- **활성 조건:** 기록 작성 화면 진입 시

### 기록 저장
- **목적:** 입력한 기록을 하나의 기록으로 저장한다.
- **상세 요소:** 기록 남기기 버튼
- **기능 설명**
  - 기록 남기기 버튼 선택 시 기록을 저장한다.
  - 저장 완료 후 인사이트 화면으로 이동한다.
  - 동일 저장 요청은 중복 처리하지 않는다.
- **활성 조건:** 기록 남기기 버튼 선택 시

### 가치 및 고민 상태 선택
- **목적:** 기록의 가치와 고민 상태를 저장한다
- **상세 요소:** 가치 목록, 고민 상태 선택
- **기능 설명**
  - 가치를 1개 선택한다.
  - 고민 상태를 고민 중 또는 정리됨 중 선택한다.
- **활성 조건:** 기록 마지막 단계 진입 시

### 이어쓸 고민 조회
- **목적:** 진행 중인 고민을 선택하여 이어쓰기할 수 있도록 한다.
- **상세 요소:** 이어쓰기 탭, 고민 목록
- **기능 설명**
  - 이어쓰기 탭에서 진행 중인 고민을 조회한다.
  - 정리된 고민은 조회하지 않는다.
  - 고민 선택 시 이어쓰기 화면으로 이동한다.

  •**활성 조건:** 이어쓰기 탭 선택 시

### 지난 기록 조회
- **목적:** 이전 기록을 참고하며 이어쓰기할 수 있도록 한다.
- **상세 요소:** 지난 기록 목록
- **기능 설명**
  - 동일 고민의 지난 기록을 최신순으로 조회한다.
  - 지난 판단을 참고하여 새로운 기록을 작성할 수 있다.
- **활성 조건:** 이어쓰기 화면 진입 시

### 이어쓰기 기록 작성
- **목적:** 기존 고민에 새로운 기록을 추가한다.
- **상세 요소:** 고민 제목, 지난 기록, 판단 입력, 이유 입력
- **기능 설명**
  - 선택한 고민의 지난 기록을 조회한다.
  - 새로운 판단과 이유를 입력한다.
  - 기존 고민 제목과 주제는 수정할 수 없다.
- **활성 조건:** 이어쓸 고민 선택 시

## 인사이트

### 인사이트 메인 조회
- **목적:** 사용자의 고민 기록을 분석하여 가치 분포와 변화 인사이트를 제공한다.
- **상세 요소:** 주제별 가치 인사이트, 가치 변화 추이, 한눈에 보는 인사이트, 기록 목록, 통합 필터
- **기능 설명**
  - 인사이트 화면 진입 시 기본 필터 기준으로 데이터를 조회한다.
  - 조회된 결과를 모든 인사이트 영역에 동일하게 반영한다.
  - 데이터 변경 시 최신 결과를 즉시 반영한다.

  •**활성 조건:** 인사이트 탭 진입 시

### 통합 필터
- **목적**: 원하는 조건의 기록만 조회하여 인사이트를 확인한다.
- **상세 요소**: 기간, 주제, 가치, 적용하기, 초기화
- **기능 설명**:
  - 기간, 주제, 가치 필터를 동시에 선택할 수 있다.
  - 적용하기 선택 시 모든 인사이트를 다시 조회한다.
  - 조회 결과가 없어도 필터 조건은 유지한다.
  - 초기화 시 기본값으로 복원한다.
- **활성 조건**: 통합 필터 선택

### 기간 선택
- **목적**: 원하는 기간의 기록을 조회한다.
- **상세 요소**: 오늘, 최근7일, 최근30일, 최근 1년, 직접 선택, 캘린더
- **기능 설명:** 
  - 프리셋 기간을 선택할 수 있다.
  - 직접 선택 시 시작일과 종료일을 선택한다.
  - 시작일만 선택하면 해당 날짜만 조회한다.
- **활성 조건:** 직접 선택

### 주제별 가치 인사이트
- **목적**: 주제별 가치 분포를 분석하여 가장 많이 선택한 가치를 제공한다.
- **상세 요소**: 주제 카드, 대표 가치, 가치 비율, 기록 개수
- **기능 설명:** 
  - 조회 조건에 해당하는 기록만 집계한다.
  - 기록 수가 많은 순으로 정렬한다.
  - 대표 가치 최대 4개를 표시한다.
  - 기록 개수를 선택하면 기록 목록으로 이동한다.
  - 기록이 1건 이상이면 인사이트를 생성한다.

  •**활성 조건**: 조회 결과 존재

### 가치 변화 추이
- **목적**: 기간별 가치 변화 흐름을 시각적으로 제공한다.
- **상세 요소**: Line Chart, 증가 가치, 감소 가치
- **기능 설명**:
  - 조회 기간을 4개 구간으로 분할한다.
  - 가치 비율을 선 그래프로 표시한다.
  - 가장 증가한 가치와 감소한 가치를 제공한다.
  - 기록이 2건 이상인 경우에만 변화 분석을 수행한다.

  •**활성 조건**: 조회 결과 기록 2건 이상

### 한눈에 보는 인사이트
- **목적**: 핵심 분석 결과를 요약하여 제공한다.
- **상세 요소**: 대표 주제, 대표 가치, 요약 문구
- **기능 설명**: 
  - 가장 많이 기록한 주제를 표시한다.
  - 대표 가치를 함께 표시한다.
  - 선택한 조회 조건에 맞는 요약 문구를 생성한다.
  - 기록이 1건 이상이면 요약을 생성한다.
- **활성 조건**: 조회 결과 존재

### 기록 목록 조회
- **목적**: 조회 조건에 해당하는 기록을 목록 형태로 제공하여 사용자가 원하는 고민을 탐색하고 상세 이력을 확인할 수 있도록 한다.
- **상세 요소**: 고민 제목, 날짜, 대표 가치, 판단 내용
- **기능 설명**:
  - 선택한 조회 조건(기간, 주제, 가치)에 해당하는 기록만 조회한다.
  - 기록은 최신순으로 정렬하여 표시한다.
  - 각 기록에는 고민 제목, 작성 날짜, 대표 가치, 사용자가 작성한 판단 내용을 표시한다.
  - 각 기록에는 **기록 작성 날짜**를 표시한다.
  - 기록을 선택하면 해당 고민의 타임라인 화면으로 이동한다.
- **활성 조건**: 조회 결과가 1건 이상 존재하는 경우
- **비고:** 조회 결과가 없는 경우에는 **INS-001(인사이트 조회)** 의 `전체 인사이트 생성 불가` 정책을 따른다

### 고민 타임라인 조회
- **목적**: 하나의 고민에 대한 기록을 시간순으로 제공하여 고민의 변화 과정을 확인할 수 있도록 한다.
- **상세 요소**: 고민 제목, 고민 주제명,기록 개수, 기록 일시, 대표 가치, 판단 내용, 타임라인
- **기능 설명:**
  - 선택한 고민의 전체 기록을 조회한다.
  - 현재 인사이트 필터 조건과 관계없이 해당 고민의 모든 기록을 표시한다.
  - 최초 기록부터 최신 기록까지 오래된 순으로 정렬한다.
  - 화면 상단에는 고민 제목, 주제, 기록 개수를 표시한다.
  - 각 타임라인에는 기록 일시, 대표 가치, 판단 내용을 표시하여 고민의 변화 과정을 확인할 수 있도록 한다.
- **활성 조건**: 기록 목록에서 특정 기록을 선택한 경우

## 설정

### 설정 조회
- **목적:** 사용자가 서비스 이용과 계정 관리를 위한 기능에 접근할 수 있도록 한다.
- **상세 요소:** 기록 가이드, 로그아웃, 회원 탈퇴, 앱 버전
- **기능 설명:**
  - 설정 화면 진입 시 기록 가이드, 로그아웃, 회원 탈퇴 메뉴를 표시한다.
  - 화면 하단에는 현재 앱 버전을 표시한다.
  - 각 메뉴 선택 시 해당 기능으로 이동하거나 실행한다.

  •**활성 조건:** 설정 탭 진입

## 기록가이드

### 기록 가이드 조회
- **목적:** 사용자가 기록 기준을 이해할 수 있도록 안내한다.
- **상세 요소:** 주제 탭, 가치 탭
- **활성 조건:** 온보딩 또는 설정에서 기록 가이드 화면에 진입한 경우
- **기능 설명**
  - 기록 가이드는 주제와 가치 두 개의 탭으로 구성한다.
  - 탭 선택 시 해당 가이드를 조회한다.• 최초 온보딩에서 기록 가이드를 제공한다.
  - 설정에서도 동일한 내용을 다시 조회할 수 있다.
